# FieldServiceApp

Trazabilidad de servicios de campo en oil & gas.

## Estructura actual

- `frontend/`: foundation de React + TypeScript + Vite para el Módulo 1.
- `docs/frontend/`: plan, arquitectura, matriz de pantallas, brechas API y wireframes.
- `certificacion-servicios-analisisv1.md` y `certificacion-servicios-analisisv3.md`: documentos de análisis funcional existentes.

El frontend está en construcción sobre la rama `frontend/foundation`. El contrato fijado corresponde al backend auditado en `bbf42b5`; las pantallas de negocio con consultas o respuestas incompletas permanecen bloqueadas. El backend corregido se comparará antes de integrar esas pantallas.

Las instrucciones para ejecutar la base están en [`frontend/README.md`](frontend/README.md).
